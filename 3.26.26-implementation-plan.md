# Carrillo Dynamics - 3.26.26 Structural & Aesthetic Pivot

## 1. Vision: "Industrial Mono"
A total shift from the "Cyberpunk/Sentry" aesthetic toward a disciplined, high-authority **"Professional Engineering"** look. The goal is to present Carrillo Dynamics as a clinical operations engineering firm rather than an automation script agency.

### Visual Identity
- **Palette**: Total removal of gradients and glows.
  - Background: `#050505` (Deep Charcoal/Black)
  - Borders: `1px solid #1a1a1a` (Sharp, discipline-focused)
  - Primary Text: `#FFFFFF`
  - Muted Text: `#a1a1a1`
- **Typography & Scale**:
  - `Inter`: Primary headers (font-black, tracking-widest) and prose.
  - `JetBrains Mono`: All numerical data, technical labels, and performance metrics.
- **The Green Pulse (Tactical Accent)**:
  - Action Green: `#10b981` (Standard Tailwind green-500).
  - Use: Numerical data, "CD" logo elements, and active state icons.
  - Constraint: NO backgrounds, glows, or large-scale pulses. Tactical only.
- **Form UX & Legibility (Industrial 2.3)**:
  - Input Background: `#000000` (Pure Black), Padding `p-4`.
  - Labels: `text-white`, `text-xs`, `uppercase`, `tracking-widest`.
  - Borders: `1px solid #3f3f46` (zinc-700).
  - Focus: Glow transition to `Solid White`.
- **Contrast Standard**:
  - Secondary/Muted/Grey text: Standardized to `zinc-400` across all sub-headers and components.
- **Layout Architecture**:
  - 12rem vertical whitespace between sections.
  - ROI Calculator: `Gap-20` on desktop, doubled font scale for main metrics.
  - Single-column focus (eliminating the Bento grid density).
  - Sharp corners on all UI elements (Card/Button/Input).
  - No duplicate components.
