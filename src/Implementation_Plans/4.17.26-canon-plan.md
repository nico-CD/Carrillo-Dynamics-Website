## 📖 Log of Identified Structural Issues

### The "Silent" Redirect Issue
While the site currently responds to both `/en` and `/en/`, this creates "split authority" in the eyes of Google. By enforcing the "No-Slash" standard in both the Sitemap and the logic, we consolidate all ranking power into a single destination.

### The Metadata Overlap
Having static SEO tags in `index.html` while React tries to inject dynamic ones creates a "race condition" in Google's crawler. Removing the static shell ensures that only the most relevant, page-specific metadata is visible.

### The "Ghost" Sitemap
Static sitemaps often fall out of sync with new content. Automating this from the `i18n.ts` data source ensures that every new article added to the site is indexed by Google within hours, not weeks.
